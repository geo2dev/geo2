# Release Notes 5.8

## Release Date

Hub:

2026-11-26

## New Features


| **Summary** | **Description** |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hub: Display reporting period in mileage tracking PDF reports | Mileage tracking PDF exports now include the selected date range (From – To) alongside the report creation date. This makes it easier to identify the reporting period and manage exported mileage records. Learn more about [mileage tracking reports](https://help.geo2.com/web-based-hub/hub-routes#mileage-report-export). |
| Hub: PDF file support in the AI assistant | The AI assistant supports PDF file uploads in addition to images, allowing users to import delivery information and create routes directly from PDF documents. Free and Pro users can upload one file per message, while Advanced and Enterprise users can upload up to five files per message. Users can preview and remove attachments before sending a message. Learn more about the [AI assistant](https://help.geo2.com/web-based-hub/hub-ai-assistant). |
| Hub: Separate weight and volume axes on the vehicle capacity chart | The vehicle capacity chart on the Route view page now features separate, individually scaled axes for weight and volume, making both values easier to read regardless of their scale. Learn more about the [vehicle capacity chart](https://help.geo2.com/web-based-hub/hub-routes/hub-route-creation-and-planning#route-capacity). |
| Hub: Polish language support | Geo2 Hub is now available in Polish. Polish is automatically selected when the user's browser or device language is set to Polish. Users can also manually change their preferred language using the language selector in the Profile menu. |
