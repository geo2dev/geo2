# Release Notes 5.8

## Release Date

Mobile app:

2026-11-25

## New Features


| **Summary** | **Description** |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mobile app: Save preferred navigation app | You can now set your preferred navigation app by selecting the **Remember as default** checkbox when starting navigation. Geo2 will automatically open the saved app for future navigation without asking you to select it each time. You can change your preferred navigation app at any time in **Settings → Device → Navigation app**. The preference is saved locally on your device and is available on both Android and iOS. |
