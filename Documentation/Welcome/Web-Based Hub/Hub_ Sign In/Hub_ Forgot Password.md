# Hub: Forgot Password

If you have forgotten or have not set up yet your password and cannot sign in successfully, follow the link `Forgot password?` on **[Sign in](https://hub.geo2.com/en-GB/auth/signin)** page.  This will enable you to reset your Geo2 password.

![Screenshot 2026-08-27 at 12.18.29.png](blob:https:/app.pagescms.org/0af955a7-291f-490d-aa34-50fdaf410133)

After you have filled in your email address, press `Get code`. You will see a prompt for you to check your inbox for a verification code sent to the provided email address. You need to copy the code and paste it to the form in Hub:

![Screenshot 2026-08-27 at 12.19.39.png](blob:https:/app.pagescms.org/a58218f1-a975-405f-ae18-2a18fc23997b)

If you have not received an email with a verification code, press the `Resend email` button on Forgot password page, and a new code will be sent.  Once the code is pasted, press the `Continue` button.  You will be redirected to create a new password.  The password should contain at least 8 characters, 1 uppercase and lowercase, 1 number and 1 special character ( ^ $  .   { } ( ) ? " ! @ # % & / \ , > < ' : ; |  ~).

![Screenshot 2026-08-27 at 12.19.56.png](blob:https:/app.pagescms.org/b4555a4e-ffcd-465b-bb9b-0a8b29c272e6)

![Screenshot 2026-08-27 at 12.20.04.png](blob:https:/app.pagescms.org/2a8cc705-06b7-4fae-b8be-4240413dac66)

Press `Save` to create a new password. Once the password is changed, you will be logged in and redirected to Analytics page. A confirmation will appear:

![Screenshot 2026-03-27 at 13.04.18.png](/Documentation/attachments/ff5ee2d8-6885-4e43-ad0c-40797f01d1be.png)
