# Release Notes 5.2

# Release Date

Mobile app and Hub:

2026-06-16

# New Features

| **Summary** | **Description** |
| --- | --- |
| Mobile app and Hub: AI assistant voice mode | The Geo2 AI Assistant now supports Voice Mode, allowing drivers and dispatchers to interact with the platform hands-free using natural voice commands. You can create and update routes or orders, manage route statuses, navigate settings, and get instant assistance more quickly and safely — especially while on the move. To maintain full control and transparency, all AI actions are confirmed before execution. |
| Mobile app: AI assistant feedback & response rating | You can now rate AI assistant responses with thumbs up or thumbs down directly in the mobile app, helping the team better understand response quality and continuously improve the AI experience. Negative ratings open a detailed feedback form where you can report issues, add comments, and attach screenshots for review, analysis, and AI assistant optimization. |
| Mobile app: Map clustering for nearby stops | The mobile map now groups nearby stops into clusters, making routes easier to view when multiple stops are close together or located at the same address. You can tap a cluster to see a clear list of included stops with stop number, order key, address, and delivery or collection type, then open the exact stop details you need. This improves map readability, reduces marker overlap, and helps you manage dense delivery areas more efficiently. |
| Mobile app: Map address search | You can now select addresses directly from the map when adding route stops, setting route start or end points, editing orders, or creating PODs. This makes it easier to choose an exact location when the address is hard to find by typing, when working on-site, or when you want to confirm a precise pickup or delivery point visually. After moving the map pin, the app identifies the address and saves it back to the relevant route, order, or POD field, helping you create more accurate routes and reduce address entry mistakes. |
| Mobile app: Improved address search keyboard | Address search now opens a keyboard with letters and digits available together. This makes entering street names, building numbers, postal codes, and apartment details faster, reducing the need to switch between text and numeric keyboards while searching for addresses. |
| Mobile app: Compact address display on stop forms | Add/Edit stop forms now display addresses in a more compact format, making the form easier to read and reducing unnecessary scrolling. The stops counter spacing has also been cleaned up, giving your a neater and more consistent stop editing experience. |
| Mobile app: Route actions moved to 3-dot menu | Route actions on the mobile Route view page have been reorganized into a vertical 3-dot menu next to the route key, creating a cleaner and less cluttered interface. This update makes important route management actions easier to access in one consistent place while giving you more space to focus on route details and stops. |
| Mobile app: Retry geocoding for stops with missing coordinates | The mobile app now detects route stops and breaks with saved addresses but missing coordinates, helping prevent optimization failures caused by invalid `0,0` locations. When the you are online, you can update affected stop locations directly from the Route view instead of manually deleting and re-adding stops. This makes offline stop creation more reliable and helps routes recover automatically once internet connection is restored. |
| Mobile app: Default vehicles for newly created environments | New environments now automatically include default vehicles for common delivery types: Truck, Van, Car, Motorbike, and Bicycle, with predefined speed factors for more accurate route planning from the start. Multiple vehicle creation is also available for all subscription levels, giving every user more flexibility to manage their fleet without subscription restrictions. |
| Mobile app: Including break statuses in “Undelivered only” filtering on Route view page | The “Undelivered only” toggle on the mobile Route view now also takes break statuses into account. When enabled, you see only stops without PODs and uncompleted breaks, making it easier to focus on remaining route tasks while hiding already completed items. |
| Hub: Image upload support for AI assistant | You can now upload screenshots and photos directly in the AI Assistant chat, making it easier to ask contextual questions and get faster support. This feature enables practical use cases such as sharing screenshots of settings, errors, routes, or system configurations so you can ask the AI assistant what a specific option means or how to use it. |
| Hub: Grid view for routes and orders | You can now switch between the existing card view and a new grid view in routes and orders lists. The grid view makes it easier to scan, compare, and manage large volumes of routes or orders, with configurable columns so you can focus on the information most relevant to your daily workflow. |
| Hub: Refreshed design | Geo2 Hub now comes with a refreshed, modern design inspired by the mobile app experience. The updated interface delivers a cleaner look, improved usability, and a more consistent experience across web and mobile platforms, helping you navigate daily operations more intuitively and efficiently. |
