# Release Notes 5.1

## Release Date

Hub:

2026-04-23

## New Features

| **Summary** | **Description** |
| --- | --- |
| Hub: Feedback mechanism for AI assistant responses | Added a feedback mechanism for AI assistant responses, allowing you to rate each message with thumbs up/down and provide detailed feedback for negative responses via a structured form with selectable issues, comments, and file attachments. |
| Hub: Vehicle categories for AI route building | Added a “Vehicle categories” selector to the AI route building dialog, allowing you to control which vehicle types are included in route building, with all categories selected by default. |
| Hub: Default vehicles for new environments | Introduced automatic creation of five default vehicles (truck, van, car, motorbike, bicycle) with predefined speed factors for every new environment, ensuring faster onboarding and immediate usability. Updated vehicle selection logic on route creation to improve defaults, including setting “Van” as the initial vehicle when no depot is selected, while preserving existing filtering behavior. Additionally, multiple vehicle support is now available across all subscription levels. |
| Hub/Mobile app: Providing information about organization and environment settings via AI assistant | Expanded the AI assistant to answer questions about available settings and access within Hub and the mobile app, including what actions are allowed based on organization and environment roles. |
| Hub/Mobile app: Providing information about route with stops in it via AI assistant | Expanded the AI assistant to provide route-level information with stops, helping you quickly access relevant route details directly in Hub and the mobile app. |
| Hub/Mobile app: Route start/completion via AI assistant | Expanded the AI assistant to support route start and completion actions directly in Hub and the mobile app, while respecting role-based permissions so only authorized users can perform these operations. |
| Hub/Mobile app: Route optimization/calibration via AI assistant | Expanded the AI assistant to run route calibration and optimization directly in Hub and the mobile app, including optimization with or without time windows when route conditions and subscription access allow, with results saved automatically. The update also respects role-based permissions, and provides clearer guidance when actions are unavailable due to route setup, permissions, or subscription level. |
