# Release Notes 5.0

# Release Date

Hub:

2026-03-19

Mobile app:

2026-04-23

# New Features

| **Summary** | **Description** |
| --- | --- |
| Hub: Geo AI Assistant | **Geo2 Hub 5.0 introduces the new Geo AI assistant**, built directly into Hub to help you plan and manage deliveries faster. You can create and update routes, assign drivers and vehicles, add stops to routes, and edit delivery details using simple text or voice commands. The new “Ask anything” field allows you to quickly execute actions or get instant answers about Geo2 features and workflows. The assistant can also navigate you to the correct page while keeping the dialog open, so you stay in context. It reduces manual work, minimizes errors, and helps you complete daily planning tasks in seconds. |
| Mobile app: Geo AI Assistant | The new **Geo AI Assistant** is designed to help you work faster and more efficiently in the mobile app. You can now **create and update routes**, **add or edit stops**, and **navigate** across key sections like Routes, PODs, and Settings using simple text or voice commands. The assistant also provides **step-by-step guidance** on how to use features such as creating routes, recording PODs, or scanning addresses. It is accessible from multiple key screens in the app, ensuring help is always within reach without interrupting your workflow. <br/> The AI Assistant adapts to your role, offering relevant suggestions and actions based on your permissions. You can also move the assistant on your screen or hide it anytime from the menu. **Free and Pro** users can use **up to 10 AI requests per day**, while **Advanced and Enterprise** users enjoy **unlimited** access. |
| Mobile app: Multi-address scanning | You can now **scan multiple addresses in one go** when adding stops to a route, making bulk stop creation faster and easier. As you scan, each address is instantly captured into a list where you can review or remove entries before confirming. <br/> Once confirmed, you can select which addresses to add to your route, giving you full control over your stops. If you scan only one address, the app skips the extra steps and takes you straight to the results. |
| Mobile app: Bulk address paste | You can now add multiple stops at once with **bulk address paste**. Simply copy your list of addresses, paste it into the app, and we will automatically search and match each one. Review the results, make edits if needed, or deselect any stops before confirming. Once confirmed, all selected addresses are instantly added to your route. It’s a faster, more efficient way to plan routes without manual entry. |
| Mobile app: Route preview on Routes page | Route cards on Routes calendar page now include a **map preview with route markers** for quick visual insights. The preview reflects the same route layout you see when opening a route, in a compact format. This makes it easier to understand route details at a glance without leaving the calendar view. |
| Mobile app: Dark app theme | A new **dark mode theme** is designed to improve usability and provide a more comfortable viewing experience in **low-light conditions while driving**. |
| Mobile app: Minimum supported OS version | Version 5.0 will be available only on devices running **at least Android 12 or iOS 17**. If your device uses an older OS version, you can continue using the app, but you will not be able to install the update. |
