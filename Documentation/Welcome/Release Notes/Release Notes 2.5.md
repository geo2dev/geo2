# Release Notes 2.5

## Release Date

2023-08-18

Bug fixes.

## New Features

| **Key** | **Summary** | **Description** |
| --- | --- | --- |
| IBALDEV-3002 | Web UI: SMS integration | Added the possibility to send an SMS notification with a public tracking link to a consignee's mobile phone number. You can read more about it [here](https://balloonone.atlassian.net/wiki/spaces/BALDEVGEO/pages/23101850/Environments#Environments-Publictracking). |
| IBALDEV-3438 | Web UI: No 'Recorded By' for POD details | Added the "Recorded by" field to display the driver's name on the POD page, POD popup, public POD page, and POD PDF file. |
| IBALDEV-3541 | Web UI: Notify about pending status of picture in POD | Added the text notification "Picture is loading, please wait" on the POD page if a picture is in Pending status (e.g. because of a bad internet connection). |
| IBALDEV-3349 | Web UI: Reset filters when organization/environment is changed | Added automatic filters resetting after organization/environment change on the Consignments, Loads, and Vehicle checks pages. |
| IBALDEV-3448 | Web UI: Import improvement | Added the possibility to import up to 500 consignments at once. |
| IBALDEV-3727 | Mobile app: Use coordinates for navigation | Improved navigation process sends co-ordinates instead of addresses to navigation app |
