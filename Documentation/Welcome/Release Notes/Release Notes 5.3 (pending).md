
# Release Notes 5.3 (pending)

Hub:

2026-07-09

# New Features

| **Summary** | **Description** |
| --- | --- |
| Hub: Import orders from screenshots and PDFs with AI | You can now **import orders directly from screenshots, photos, and PDFs** using Geo2 AI. The system automatically extracts addresses and additional delivery information, including contact details, delivery instructions, order keys, time windows, package counts, and stop types. Before importing, you can review and edit the detected data to ensure accuracy. Orders can be imported directly into the **Orders page, Route view, or Map view**, or created through the **AI Assistant** by uploading screenshots/files in the chat. The feature supports extracting multiple orders from a single file to reduce manual data entry and speed up route planning. |
| Hub: Expanded AI Assistant capabilities | The Geo2 AI Assistant can now handle even more route planning tasks while better understanding your current workflow. It automatically uses the context of the page you are viewing, allowing you to optimize routes, create and add stops, move or remove orders, and manage driver breaks with fewer follow-up questions. The assistant can also provide route information, suggest route optimization when changes are made, and intelligently choose the best optimization method based on your route and subscription level. Together, these updates make interacting with the AI Assistant faster, more natural, and more productive. |
| Hub: Multi-select filtering for routes and orders | You can now select **multiple values within the same filter** when searching for routes and orders. For example, the Depot filter allows you to display results from multiple depots at the same time, eliminating the need to switch between separate filter values. Multi-select filtering is available across route and order workflows, including Routes, Orders, Route view, and Map view. This makes it easier to narrow down results and quickly find the routes or orders you need. |
| Hub: Improved template management for order and route filters | The updated template selector clearly shows which template is currently applied and provides **quick access to create, edit, or delete templates**. When creating or editing a template, the current filtering and sorting settings are pre-filled and can be adjusted before saving. The active template is also displayed in the Route view and Map view drawers, making it easy to see which template is being used while adding routes or orders. |
| Hub: Expand or collapse all stops at once | You can now **expand or collapse all stop cards within a route with a single click**. This is available on both Route view and Map view, making it easier to review delivery details, contact information, notes, and other stop data without opening each stop manually. The button changes automatically between **Expand all** and **Collapse all** depending on the current state of the stop cards. |
| Hub: Display Channel and Area on stop cards | You can now display **Channel** and **Area** information directly on stop cards in Route view and Map view. These fields are available in the **Stop card layout settings** and can be enabled for both collapsed and expanded stop card views. This gives you more flexibility to customize stop cards and see the information most relevant to your workflow. |
| Hub: Display up to 40 routes in Map view | The Map view now supports displaying up to **40 visible routes** at once. This allows you to review and compare more routes directly on the map without switching between smaller route groups. Route card colors are automatically generated to make each route easier to distinguish visually. |
| Hub: Customizable route key generation | You can now **customize how route keys are generated** automatically in Geo2 Hub. Choose which elements to include, such as the current date, time, trip number, depot, vehicle, or area. Your selected format is applied consistently whenever routes are created, including manual route creation, AI-assisted workflows, and order imports. Automatically generated route keys can still be edited before saving if needed. |
| Hub/API: Automatic order export by route status | You can now define when orders assigned to a route should be exported automatically. In Route settings, choose a route status such as Planned, Released, Started, or Completed to trigger the export when a route reaches that status. If Manual is selected, automatic export remains disabled. This gives API integrations more control over when route order data is sent for export. |
