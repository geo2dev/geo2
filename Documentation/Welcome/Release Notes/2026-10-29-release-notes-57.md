# Release Notes 5.7

## Release Date

Hub: 

2026-10-29

## New Features


| **Summary** | **Description** |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Hub: Analyze your operations with AI | Geo2 AI Assistant now supports AI-powered analytics, making it possible to analyze delivery operations using natural language. Instead of manually configuring charts and reports, simply ask questions about routes, orders, drivers, vehicles, and overall delivery performance to get the insights you need. It analyzes your operational data and presents the results through clear summaries, key metrics, tables, and automatically generated charts.Track delivery performance, compare drivers, analyze vehicle capacity utilization, explore CO₂ emissions, and identify trends across different time periods. The AI Assistant can also combine multiple metrics to provide a broader overview of operations, helping identify performance changes and areas that may need attention.Continue exploring results through follow-up questions without starting a new analysis. For example, ask ***"How did our drivers perform last week?"***, then follow up with ***"Compare the top three drivers"*** or ***"Show their on-time delivery rates in a chart."***This feature is available in Geo2 Hub with **Advanced and Enterprise subscriptions**, subject to account permissions and available analytics data. |
| Hub: Route purpose codes & mileage reports | Geo2 Hub now supports route purpose codes and mileage report export, making it easier to categorize routes, track actual distances, and generate mileage reports for your delivery operations.Route purpose codes allow you to assign a specific purpose to each route, such as Delivery round, Client visit, Commute to depot, or Personal use. Environment Admins can create, edit, and manage custom purpose codes under **Settings → Route purpose codes**. Each purpose code is associated with one of three predefined categories: Business, Commuting, or Personal. A default purpose code can also be configured to be automatically assigned when creating new routes.The selected purpose code is displayed in the route details and directly on route cards, making it easy to identify the purpose of each route. A new Purpose code filter is also available on the Routes page, allowing you to filter routes by one or multiple purposes alongside existing filters such as date, driver, vehicle, and route status.In addition, a new **Export mileage report** option is available on the Routes page. Mileage reports can be generated for all completed routes matching the applied filters or for specific completed routes selected manually. This makes it possible to prepare reports for different drivers, vehicles, route purposes, or accounting periods without manually collecting mileage information.Mileage reports can be exported in **CSV, PDF, or XLSX format** and include detailed information about each completed route, such as its route key, purpose code, assigned driver and vehicle, actual start and end times, starting and ending locations and addresses, and actual distance travelled. Each report also includes the total number of routes and total actual distance for the selected records.Mileage Report Export is available with **Pro, Advanced, and Enterprise subscriptions** for Environment Admins and Managers. |
| Hub: Drag-and-drop order assignment & route rescheduling in Calendar view | Geo2 Hub now supports additional drag-and-drop capabilities in **Routes → Calendar View**, making it easier to assign orders to routes and reschedule routes directly from the calendar without opening and editing each route individually. A new **Add orders** button is available in Calendar view, providing access to the existing order selection panel. By default, the panel displays unassigned orders, with additional filtering and sorting options available to help find specific orders. To assign an order, simply drag it from the Add orders panel and drop it onto the desired route card in the calendar.Orders can be assigned to routes across different dates displayed in the calendar, without expanding route cards or opening individual routes. Once an order is assigned, it is automatically added to the end of the route's stop list, and the route card is updated to reflect the changes, including the number of stops, weight, and volume where applicable. Valid drop targets are highlighted during dragging, while existing route assignment restrictions, such as depot compatibility, continue to apply.In addition to order assignment, **route cards can now be dragged and dropped between dates in Calendar view** to quickly reschedule routes. Simply drag a route card from its current date to another date in the calendar, and the route's planned start date will be updated automatically. The original start time and other route details remain unchanged. |
